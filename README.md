# 双槽 Dual Slot

双槽是一款专门为通才者设计的应用

Dual Slot is an app built specifically for generalists.

## 设计初衷（Why it exists）

这里说的通才者，接近 Paul Genberg 在 [《The Value of Being a Generalist》](https://www.forbes.com/councils/forbesbusinesscouncil/2021/06/03/the-value-of-being-a-generalist/) 里的定义：通才者是爱探索、爱学习、愿意在不同题目上动手的人，对许多领域有广的了解，又在少数几处有深度。文章强调，专才像一只「金笼子」，只能沿一条轨道上下；通才者的价值往往是把点连成线、看见专家未必看见的关联，而不是样样第一。历史上走这条路的人并不少，例如达芬奇、沈括、本杰明·富兰克林。

常见专注工具默认「一次只做一件事」，再用锁屏、屏蔽 App 来强迫执行。通才者往往不是做不到专注，而是脑子里同时有几条线在干扰注意力：正在推进的主课题、必须应付的杂事，以及随时冒出来、丢掉就可惜的新想法。如果硬压成单任务，要么副线被牺牲，要么灵感被当成干扰删掉。

[斯坦福人生设计课](http://lifedesignlab.stanford.edu/dyl)（Bill Burnett、Dave Evans，《[Designing Your Life](https://designingyour.life/)》）里有一个很实用的观察：人在选项特别多的时候，常常不是选错，而是干脆不选。这和选择过载的研究一致：在[Sheena Iyengar 与 Mark Lepper 的果酱货架实验](https://doi.org/10.1037/0022-3514.79.6.995)里，研究者发现商店摆出 24 种果酱比只摆 6 种更能让人停下来看，真正买走的比例却更低——选择本身会消耗人的精力，当选择多到一定程度时，行动就会停住。人生设计课的对策也不是「再想清楚一点」，而是先把选项收缩到能比较的几条，再靠行动和原型去试，而不是把大把精力耗在比较上。

双槽把「同时只推进两件」做成结构，就是为了少花力气在无数念头之间做选择，多花力气做掉眼前这两件：

- **主任务 / 副任务**：当下允许占用时间的两个执行位，各自有每日最低时长。
- **缓存区**：其余计划先停放、可拖拽排序，而不是消失，也不用立刻决定永远放弃。
- **习惯**：每天有时限、需要反复完成的事，和一次性计划分开。
- **回流区**：做完的事留下耗时，可以再排队；默认不删除。
- **进度统计**：用主副达标和习惯用时看一天，而不是用「清空待办」当成功。

做成一件，会反过来让下一件更好启动。Teresa Amabile 与 Steven Kramer 在《The Progress Principle》和文章[《The Power of Small Wins》](https://hbr.org/2011/05/the-power-of-small-wins)里归纳过类似现象：对内在工作状态提升最大的，往往不是奖励或休息，而是在有意义的事情上取得哪怕很小的进展（他们称为「小胜」）。进度被看见、完成不被蒸发，比空的待办清单更接近这种激励。这是设计上的猜想，也有上述研究托底，但不是说装了这个软件就一定会产生同样的效果。

不做手机封锁。界面偏安静，计时、闹铃和可选的背景音乐用来陪你做完该做的两件事，并给其余念头一个去处。数据只留在本机。

Here, a generalist is close to Paul Genberg’s account in [“The Value of Being a Generalist”](https://www.forbes.com/councils/forbesbusinesscouncil/2021/06/03/the-value-of-being-a-generalist/): someone who likes to explore, to learn, and to try different subjects, with broad knowledge across many fields and depth in a few. The article treats specialization as a golden cage that only moves you up and down one track; a generalist’s value is often connecting dots and seeing links specialists may miss, not being first at everything. History has no shortage of people on this path, such as Leonardo da Vinci, Shen Kuo, and Benjamin Franklin.

Most focus apps assume you should do one thing at a time, then enforce that with lock screens and blocked apps. Generalists often are not unable to focus. Several threads at once pull on their attention: a main project underway, chores that still have to be handled, and new ideas that would hurt to throw away. If that is forced into a single task, either the side thread is sacrificed or the idea is treated as noise and deleted.

[Stanford’s Life Design course](http://lifedesignlab.stanford.edu/dyl) (Bill Burnett and Dave Evans, *[Designing Your Life](https://designingyour.life/)*) has a practical observation: when there are too many options, people often do not pick the wrong one — they pick nothing. That matches research on choice overload: in [Iyengar and Lepper’s jam-aisle study](https://doi.org/10.1037/0022-3514.79.6.995), the researchers found that a store display of 24 jams drew more people to stop and look than a display of 6, but a smaller share actually bought anything. Choice itself spends a person’s energy; when there is enough of it, action stalls. Life Design’s answer is not “think a bit harder.” It is to shrink the set to a few comparable paths, then try them through action and prototypes, instead of pouring hours into comparing.

Dual Slot turns “only two things in motion” into structure, so less energy goes to choosing among endless thoughts and more goes to finishing the two in front of you:

- **Primary / Secondary**: the two slots allowed to take time today, each with a daily minimum.
- **Parking**: everything else waits, can be drag-sorted, and does not vanish. You do not have to abandon it forever right now.
- **Habits**: work with a daily time quota, kept apart from one-off plans.
- **Reflux**: finished work keeps its duration and can re-enter the queue. Deleting is not the default.
- **Stats**: a day is “met” when primary, secondary, and habit quotas are met — not when a todo list is empty.

Finishing one thing makes the next easier to start. Teresa Amabile and Steven Kramer describe a similar pattern in *The Progress Principle* and [“The Power of Small Wins”](https://hbr.org/2011/05/the-power-of-small-wins): the largest lift to inner work life is often not rewards or rest, but even a small step on work that matters (“small wins”). Making progress visible, and not evaporating completed work, is closer to that kind of fuel than an empty list. That is a design bet, backed by the research above. Installing the app does not guarantee the same effect.

No phone blocking. The UI stays quiet. A timer, an alarm, and optional background music sit with you while you do the two things that belong in the slots, and give other thoughts a place to land. Data stays on this device.

## 关于制作者（About the author）

我从小到现在，一直同时对很多事情感兴趣，而且几乎每周都会冒出新的想法、新的想做的事。这很困扰我：很难把注意力收到一个方向上；做选择时更难受——不是完全选不出来，而是会一直惦记那些没有走的路。

我也有比较丰富的个人经历。做过桌游、做过视频，在医学院跟导师做过研究、当过编程课助教、编过几款游戏。对任何知识习惯性保持开放，对科学、人文、历史、心理、哲学、宗教、艺术这几个板块都有浓厚的兴趣。这些对我来说不太像一份爱好清单，更像看待这个世界不同的角度。

学习时我还会产生另一种走神。读书或看科普视频时，大脑有时不受控制地把新内容和自己已有的知识框架接上。注意力会被动地拽进这些连接里，有时连接过程中甚至会进入心流状态（在外人看来，就像发呆一样）；等回过神来，原来那本书或那支视频已经有点看不下去了。双槽想处理的，不完全是懒或没毅力，而是念头来得太快、联系来得太密——如果没有一个地方先把它们放下，当下那一件事就站不住。

我有过一段时间就坠入了上述所说的选择陷阱，为了逃避大脑不断涌现的想法，我只能通过电子游戏和影视作品来麻痹自己，然而我始终知道这种行为本身无法解决任何问题，甚至会助长个人的焦虑情绪，于是就有了这个 App。

From childhood through now I have been interested in many things at once, and almost every week a new idea or a new thing I want to do shows up. That has been hard: it is difficult to pull attention onto one direction, and choosing is worse — not because I cannot choose at all, but because I keep minding the paths I did not take.

I also have a fairly mixed set of experiences. I created board games, made videos, did research with a supervisor in medical school, TA’d programming courses, and programmed games. I tend to stay open to any field, and I have a strong interest in science, the humanities, history, psychology, philosophy, art, and religion. For me this is less a hobby list than different viewing angles on the same world.

Learning brings another kind of drift. When I read or watch explainers, my mind sometimes uncontrollably hooks the new material into the framework I already have. Attention is pulled into those connections; sometimes the connecting itself goes into flow (from the outside it can look like zoning out). When I come back, it is already a bit hard to stay with the book or the video. Dual Slot is not only about laziness or willpower. Thoughts arrive too fast and links arrive too densely. If there is nowhere to set them down first, the thing in front of you cannot stand.

I spent a stretch of time falling into that choice trap. To get away from the ideas that kept showing up, I numbed myself with video games and films. I always knew that did not solve anything, and it even fed the anxiety. This app came out of that.

## 适用人群（Who it is for）

更适合：

- 研究、创作、自学时会多个任务并行的人
- 工作里经常是「一件主课题 + 一件杂务」同时在场的人
- 用过番茄钟或屏蔽类 App，觉得强制单任务、或做完即删不舒服的人
- 容易拖着不开工、想找一个开始结构的人，或希望养成每日习惯的人

不太适合：

- 需要严格 GTD、项目协作、多人同步的团队
- 主要靠锁定手机、屏蔽应用才能开始做事的人（本应用不提供这些）

A better fit if you:

- often run several tasks in parallel while researching, making, or teaching yourself
- often have “one main project plus one chore” on the table at work
- have tried Pomodoro or blocker apps and disliked forced single-tasking or delete-on-done
- often stall before starting, want a structure for getting going, or want to build a daily habit

A poorer fit if you:

- need strict GTD, team projects, or multi-person sync
- mainly start work by locking the phone and blocking apps (this app does not do that)

## 怎么用（How to use it）

1. **缓存区**：添加标题、内容、标签；勾选完成后是否进入回流。把条目拖到主任务（默认每天 90 分钟）或副任务（默认 30 分钟）。
2. **习惯**：添加每天有最低时长的事；达标按当日时限计算，不进入回流区。
3. **执行**：大时钟。计时或倒计时。选当下任务（含习惯）、闹铃和背景风格。倒计时结束会提示任务完成。背景音乐在底栏，和计时器独立。
4. **回流区**：看完成项的耗时，重新排队或删除。
5. **进度统计**：每日用时、主副与习惯是否达标、累计达标天数、近 30 天、月/年汇总。

数据只存在本机（浏览器 IndexedDB、桌面 exe 或手机 App 内的 WebView）。这几种环境互不同步。

1. **Parking**: add a title, notes, and tags; choose whether done items go to Reflux. Drag an item onto Primary (default 90 minutes a day) or Secondary (default 30).
2. **Habits**: add work with a daily minimum. Meeting the quota counts for that day; habits do not go to Reflux.
3. **Focus**: a large clock, count-up or countdown. Pick the current task (including habits), the alarm, and the scene. When a countdown ends, it shows that the session is done. Background music lives in the bottom bar and is independent of the timer.
4. **Reflux**: see time spent on finished items; re-queue or delete.
5. **Stats**: time today, whether primary / secondary / habits met quota, days met, last 30 days, month and year totals.

Data stays on this device (browser IndexedDB, the desktop exe, or the phone WebView). Those stores do not sync with each other.

## 电脑本地使用（Using it on a PC）

两种方式，由易到「真正的 exe」：

**1. Edge / Chrome 安装成桌面应用（最方便，不用打包）**

```bash
npm run dev
```

用 Edge 或 Chrome 打开 http://localhost:5173/ ，地址栏右侧或菜单里选 **安装双槽** / **安装应用**。之后开始菜单和桌面会有图标，窗口里没有浏览器标签栏。第一次安装时开发服务器要开着；装好后若离线缓存生效，也可以单独打开。数据存在该浏览器的配置里。

**2. 打成便携 exe（双击即用，不依赖终端）**

```bash
npm run desktop
```

会打开一个桌面窗口，用来确认效果。要生成可拷贝的安装文件：

```bash
npm run desktop:exe
```

产物在用户主目录下的 `DualSlotBuild`（例如 `%USERPROFILE%\DualSlotBuild\双槽-0.0.0-portable.exe`），不放在项目文件夹里，避免 Windows 占用导致打包失败。拷到任意位置双击即可。数据和浏览器不是同一份。

Two paths, from easy to a real exe:

**1. Install from Edge / Chrome (easiest, no packaging)**

```bash
npm run dev
```

Open http://localhost:5173/ in Edge or Chrome and use **Install Dual Slot** / **Install app** from the address bar or the menu. You get a Start Menu and desktop icon without browser tabs. The first install needs the dev server running; later, offline cache may be enough to open it alone. Data lives in that browser profile.

**2. Portable exe (double-click, no terminal)**

```bash
npm run desktop
```

This opens a desktop window so you can check the build. To make a file you can copy:

```bash
npm run desktop:exe
```

Output goes to `DualSlotBuild` in your user folder (for example `%USERPROFILE%\DualSlotBuild\双槽-0.0.0-portable.exe`), not inside the repo, so Windows file locks are less likely to break the pack. Copy it anywhere and double-click. That data is not the same as the browser’s.

## 做成手机应用（Phone app, Android APK）

这是把现有网页用 Capacitor 包进系统 WebView，不是重写原生界面。Windows 电脑可以打 **Android 安装包**；**iOS 必须用 Mac + Xcode**，还需要 Apple 开发者账号才能装到非自己的 iPhone 上长期使用。

### Android

1. 安装 [Android Studio](https://developer.android.com/studio)（会带 JDK 和 Android SDK）。
2. 在项目目录：

```bash
npm run mobile:sync
npm run mobile:open
```

3. 在 Android Studio 里等 Gradle 同步结束。连上手机（打开开发者选项 / USB 调试），点 Run；或菜单 **Build → Build APK(s)** / **Generate Signed Bundle / APK**。
4. 把生成的 `.apk` 拷到手机安装。首次安装需允许「未知来源」或「通过 USB 安装」。

之后改了网页代码，再执行一次 `npm run mobile:sync`，然后在 Android Studio 里重新运行或出包。

### iOS

在 Mac 上安装 Xcode 后执行 `npx cap add ios`，再用 `npx cap sync ios` 和 `npx cap open ios`。个人测试可用免费 Apple ID 签到自己的手机（大约 7 天要重签）；上架 App Store 需要付费开发者账号。

This wraps the existing web UI in a system WebView with Capacitor. It is not a native rewrite. On Windows you can build an **Android package**. **iOS needs a Mac and Xcode**, plus an Apple Developer account for long-term install on anyone else’s iPhone.

### Android

1. Install [Android Studio](https://developer.android.com/studio) (JDK and Android SDK come with it).
2. In the project folder:

```bash
npm run mobile:sync
npm run mobile:open
```

3. Wait for Gradle to finish in Android Studio. Plug in a phone (developer options / USB debugging) and hit Run; or use **Build → Build APK(s)** / **Generate Signed Bundle / APK**.
4. Copy the `.apk` to the phone. First install may need “unknown sources” or USB install allowed.

After you change the web code, run `npm run mobile:sync` again, then rebuild or run from Android Studio.

### iOS

On a Mac, install Xcode, then `npx cap add ios`, `npx cap sync ios`, and `npx cap open ios`. A free Apple ID can sign onto your own phone for testing (re-sign about every 7 days). The App Store needs a paid developer account.
